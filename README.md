## 📁 Sobre o Repositório

Uma coletânea de todos os meus projetos realizados durante o Programa Institucional de Bolsa de Iniciação à Docência (PIBID) no Polo de Inovação do IFCE e o Curso Técnico Integrado em Informática ofertado pelo Instituto Federal de Educação, Ciência e Tecnologia do Ceará (IFCE) - Campus Fortaleza.

## 💿 Lista de Softwares

As aplicações se dividem em duas "categorias" diferentes, referenciadas logo abaixo:

#### 🔴🟩 Projetos do IFCE

1. [**Pesquisa de Saúde da Equipe Cosmo (Python + PySimpleGUI)**](./PesquisaCosmos/): introdução à programação e interface gráfica simples;
2. [**Reprodutor de Música (HTML5 + CSS3 + JavaScript)**](./ReprodutorMusica/): fundamentos do desenvolvimento web e HTML DOM (Document Object Model);
3. [**Simulador de Biblioteca (Python + PySimpleGUI)**](./BibliotecaGUI/): iniciação à programação orientada a objetos (POO), manuseamento básico de dados com arquivos `.txt` e interface gráfica de usuário (GUI);
4. [**Práticas com Banco de Dados (SQLite3 + Knex.js)**](./DatabasePractices/): conceitos de bancos de dados relacionais (teoria e prática);
5. [**Horizonte Financeiro (Swift + SwiftUI + Xcode)**](./HorizonteFinanceiro/): desenvolvimento de aplicativo iOS para didática e conscientização acerca do gerenciamento de finanças;
6. [**Loja de Jogos Virtual - Protótipo (Kotlin + XML + Android Studio)**](./PrototypeGamingStore/): noções de desenvolvimento de aplicativos móveis para Android;
7. [**Octo Team's Game Store (Kotlin + XML + Firebase + Android Studio)**](./OctoGameStore/): simulação de loja virtual e aplicação de metodologias ágeis (Milestones) no GitHub;
8. [**O Guia da Programação (HTML5 + CSS3 + Express.js + MongoDB)**](./ProgrammingGuide/): website introdutório ao mundo da programação e banco de dados não-relacional (NoSQL);
9. [**UxO-Beta (C# + Unity)**](https://github.com/AJUMP-Corp/UxO-Beta): desenvolvimento de jogo para Windows e gestão profissional de projetos com ClickUp.

#### 🤖🎲 Projetos do PIBID

1. [**Desafios com Testes (Python + Unittest)**](./UnittestChallenge/): revisão de lógica de programação com Python e testes unitários simples;
2. [**Calculadora de IMC (Python + Socket + JSON)**](./CleanCodeIMC/): práticas de Clean Code e gerenciamento de arquivos JSON;
3. [**IMC Multithread (Python + Socket + JSON + Threading)**](./IMC-Multithread/): documentação e princípios SOLID (Single Responsibility, Open-Closed, Liskov Substitution, Interface Segregation, Dependency Inversion);
4. [**Divisor de Sílabas v1.0 (Python + PySimpleGUI + PyHyphen)**](./DivisorSilabas_old/): análise silábica simples, interface gráfica de usuário (GUI) e envio de e-mails;
5. [**Automação de Testes Web (Python + Behave + Selenium)**](./WebTestAutomation/): aplicação de BDD (Behavior-Driven Development) e automação de testes em navegadores web;
6. [**Calculadora Simples (Python + PyTest + Azure DevOps)**](./TDD_Calculator/): utilização de TDD (Test-Driven Development) para testes com cálculos aritméticos;
7. [**Comunicação de Instrumentos (Python + PySerial + PyTest)**](./Instrument_Comunication/): leitura de dados via porta serial simulada e customização de Exceptions;
8. [**Ciência de Dados com Álgebra Linear (Python + NumPy + Pandas + Matplotlib + Seaborn + Scikit-Learn)**](./CienciaDados/): cálculo de matrizes, visualização estatística e previsão de resultados.

#### 🪽💧 Projetos da CAGECE

1. [**Práticas com Planilhas .xlsx (Excel + VBA)**](./ExcelPractices/): elaboração de tabelas gráficos, dashboards e macros com Visual Basic for Applications.
