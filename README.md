## 📁 Sobre o Repositório
Uma coletânea de todos os meus projetos realizados durante o Programa Institucional de Bolsa de Iniciação à Docência (PIBID) e o Curso Técnico de Informática ofertado pelo Instituto Federal de Educação, Ciência e Tecnologia do Ceará (IFCE) - Campus Fortaleza.

## 💿 Lista de Softwares
As aplicações se dividem em duas "categorias" diferentes, referenciadas logo abaixo:

#### 🔴🟩 Projetos do IFCE
1. [**Pesquisa de Saúde da Equipe Cosmo (Python / PySimpleGUI)**](./PesquisaCosmos/): Introdução à Programação e Interface Gráfica Simples;
2. [**Reprodutor de Música (HTML5 / CSS3 / JavaScript)**](./ReprodutorMusica/): Fundamentos do Desenvolvimento Web e HTML DOM (Document Object Model);
3. [**Simulador de Biblioteca (Python / PySimpleGUI)**](./BibliotecaGUI/): Iniciação à Programação Orientada a Objetos (POO), Manuseamento Básico de Dados com Arquivos `.txt` e Interface de Usuário (UI);
4. [**Práticas com Banco de Dados (SQLite3 / Knex.js)**](./DatabasePractices/): Conceitos de Bancos de Dados Relacionais (na teoria e na prática);
5. [**Horizonte Financeiro (Swift / SwiftUI)**](./HorizonteFinanceiro/): Didática e Conscientização acerca do Gerenciamento de Finanças e Desenvolvimento de Aplicações para iOS com Xcode;
6. [**Loja de Jogos Virtual - Protótipo (Kotlin / Android Studio)**](./PrototypeGamingStore/): Noções Básicas da Construção de Aplicativos Móveis para Android;
7. [**Octo Team's Game Store (Kotlin / Android Studio)**](./OctoGameStore/): Simulação de uma Loja Virtual Real e Aplicação de Metodologias Ágeis no GitHub (Milestones);
8. [**O Guia da Programação (HTML5 / CSS3 / Express.js / MongoDB)**](./ProgrammingGuide/): Desenvolvimento Web com Framework Básico, Bancos de Dados Não-Relacionais (NoSQL) e "Manual de Instruções" para quem está entrando no Mundo da Programação;
9. [**UxO-Beta (C# / Unity)**](https://github.com/AJUMP-Corp/UxO-Beta): Criação de Jogos Desktop para Windows e Gestão Profissional de Projetos com ClickUp;
10. **Outros**: _Pong Game_ (Python / PyGame / Replit)

#### 🤖🎲 Projetos do PIBID
1. [**Desafios com Testes (Python / Unittest)**](./UnittestChallenge/): Revisão de Lógica de Programação com Python e Testes Unitários;
2. [**Calculadora de IMC (Python / Sockets / JSON)**](./CleanCodeIMC/): Práticas de Clean Code e Gerenciamento de Arquivos JSON;
3. [**IMC Multithread (Python / Sockets / JSON / Threading)**](https://github.com/abraaolucassb/IMC-Multithread): Documentação e Princípios SOLID (Single Responsibility, Open-Closed, Liskov Substitution, Interface Segregation, Dependency Inversion);
4. [**Divisor de Sílabas v1.0 (Python / PySimpleGUI / PyHyphen)**](./DivisorSilabas%20(old)/): Análise Simples de Palavras, Interface Gráfica de Usuário (GUI) e Envio de E-Mails;
5. [**Automação de Testes Web (Python / Behave / Selenium)**](./WebTestAutomation/): 
6. [**Comunicação de Instrumentos (Python / Serial / PyTest)**](https://github.com/Daniel-Anastacio/Instrument_Comunication): Leitura de Dados enviados por uma Porta Serial e Customização de Exceções;
7. **Outros**: _Calculadora Simples_ (Python / PyTest / Microsoft Azure DevOps), _Fundamentos de Machine Learning e Introdução à Modelagem de Dados_ (Python / NumPy / Pandas / Matplotlib / Seaborn / Scikit-Learn / Google Colab)
